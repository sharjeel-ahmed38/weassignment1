Learning HTML Container Elements

Section One

HTML container elements help us organise the content of a web page into meaningful blocks.

They make the structure of a web page easier to understand and maintain.

Section Two

The header element is normally used for the introductory content of a web page.

It can contain headings, introductory text and other important information.

Section Three

The main element contains the primary content of a web page.

It should contain information that is directly related to the main purpose of the page.

Section Four

The section element is used to divide the main content into separate logical areas.

Each section can have its own heading and related content.

Section Five

Navigation elements are useful for providing links to different pages of a website.

A navigation menu normally contains links to important pages of the website.

Section Six

The footer is normally placed at the bottom of a web page.

It can contain copyright information, contact details and links to related pages.
